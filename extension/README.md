# Panduan 30 Detik Memasang Ekstensi ClientReach AI di Google Chrome

Ekstensi ini adalah robot asisten resmi untuk menyedot data kontak WhatsApp asli dari Google Maps langsung ke sistem ClientReach AI Anda.

### Cara Memasang (Hanya 1 Kali di Awal):

1. Buka browser **Google Chrome**.
2. Di kolom alamat (*address bar*), ketik:
   ```text
   chrome://extensions
   ```
   Lalu tekan **Enter**.
3. Di pojok kanan atas layar Chrome, aktifkan toggle:
   **Developer mode** (Mode pengembang) menjadi **ON**.
4. Di pojok kiri atas, klik tombol:
   **Load unpacked** (Muat ekstensi belum dibongkar).
5. Pilih folder:
   ```text
   c:\xampp\htdocs\Client_Reach_ai\extension
   ```
6. Selesai! Ekstensi **ClientReach AI - Google Maps Assistant** akan langsung muncul dan aktif selamanya.
